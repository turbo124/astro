Checkout.com is a global payments platform that enables businesses to process payments in real-time from clients worldwide, operating in approximately 50 countries and supporting over 150 currencies.

## Setup

1. Create a Hub account on Checkout.com's website
2. Complete registration and access The Hub dashboard
3. Navigate to Settings > Channels to locate your business account
4. Retrieve your API public key and API secret key
5. Log into Invoice Ninja and access Settings > Payment Gateways
6. Select Checkout.com and enter your API credentials
7. Set Checkout.com as your default payment gateway
8. Test the integration with a test transaction before going live
